# SOON

음악 파일을 서버에 업로드하고, 보관함에서 스트리밍하거나 플레이리스트 링크로 공유하는 웹앱입니다.

## 실행

Node.js 18 이상이 설치된 환경에서 운영자 비밀번호를 지정한 뒤 실행합니다.

```sh
ADMIN_PASSWORD='replace-with-a-strong-password' npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 업로드한 오디오와 라이브러리 정보는 프로젝트의 `storage/` 폴더에 저장됩니다. `PORT` 환경 변수로 포트를 바꿀 수 있습니다. `ADMIN_PASSWORD`가 없으면 서버는 업로드와 플레이리스트 변경을 거부합니다. 방문자는 음악과 플레이리스트를 읽고 스트리밍할 수 있고, 쓰기 작업에는 운영자 비밀번호가 필요합니다.

## 다른 사람과 공유하기

플레이리스트 화면의 **공유하기**를 누르면 현재 사이트 주소를 기준으로 공유 링크를 만듭니다. 링크를 받은 사람은 사이트에 접속해 그 플레이리스트의 음악을 스트리밍할 수 있습니다. 직접 곡 링크도 복사할 수 있습니다.

다른 네트워크의 사람과 공유하려면 이 앱을 공인 도메인에서 HTTPS로 운영해야 합니다. 배포 환경에 `ADMIN_PASSWORD` 환경 변수를 설정하고, `storage/`가 재시작 후에도 유지되는 디스크나 영구 볼륨을 연결하세요. 파일 손실을 막으려면 `storage/`를 별도로 정기 백업해야 합니다. 서비스가 무기한 보관을 보장하려면 호스팅, 저장 용량, 백업, 접근 제어를 운영자가 계속 관리해야 합니다.

## 업로드

지원 확장자: MP3, M4A, AAC, WAV, OGG, FLAC, OPUS, WEBM. 한 번의 업로드 요청은 최대 600MB입니다. 업로드한 파일은 서버 디스크에 원본 그대로 저장됩니다.
